# Inter

Unmodified Inter variable WOFF2, obtained from the official project:

- Font: https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2
- License: https://github.com/rsms/inter/blob/master/LICENSE.txt

The SIL Open Font License is included in `Inter-LICENSE.txt`.
`frontend/styles.css` serves the font locally with `font-display: swap` and a
system sans-serif fallback. No runtime CDN or npm font dependency is used.
